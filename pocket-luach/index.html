Pocket Luach Privacy Policy

Effective August 16, 2026

Pocket Luach is published by Tebeka Software Solutions. Privacy questions may be sent to haim@tebeka.com.

Privacy by design

Pocket Luach does not require an account and contains no advertising, analytics, tracking, crash-reporting, or remote-map service. It does not sell personal data.

Location

If the user taps Use current location, Pocket Luach requests approximate or precise foreground location for a one-time local calculation. The location is used on the device to select a packaged city or help create a custom location for Jewish-calendar and zmanim calculations. Pocket Luach does not request background location or Internet access and does not transmit location data.

Local storage and backup

Selected and custom locations, favorites, recents, settings, calendar state, notes, and Siddur reading state are stored in Android app-private preferences. These preferences are excluded from Android cloud backup, although a user-controlled direct device-transfer process may copy them to a new device.

Optional Birthday Tehilim information

If the user chooses to save Birthday Tehilim profiles, Pocket Luach stores any number of optional custom names, full civil birth dates, before-sunset, after-sunset, or not-sure choices, profile ordering, static Psalm numbers, and optional dynamic profile references only in an app-private no-backup file on the device. Those details are used locally to calculate Hebrew birthdays and daily personal Psalms. Each dynamic Psalm is recalculated automatically as the person’s Hebrew age changes. The information is not sent to Tebeka Software Solutions, included in Android cloud backup or device transfer, or placed in Contacts, Calendar, reminders, or notifications.

Birthday Tehilim can open Android’s system single-contact picker. When the provider makes them available, Pocket Luach immediately copies only the selected person’s editable display name and full birthday with year into the unsaved editor. It does not request broad Contacts access, retain a contact ID or URI, copy phone numbers, email addresses, postal addresses, or other contact fields, or keep ongoing access to the contact. Missing, partial, or inaccessible fields require manual entry; cancelling the picker makes no changes and does not create a saved contact link.

Birthday Tehilim does not use location, request broad Contacts, Calendar, or notification access, or create a calendar event, reminder, or notification. Its recommendations follow the Hebrew date displayed from the device’s civil date and may change at midnight rather than at the exact local sunset. Profiles and Personal Tehilim entries can be edited, reordered, removed individually, or cleared in the feature.

User-initiated sharing

Report, Daily Notes, and Tehilim chapter sharing occurs only after the user taps Share and selects a destination in Android’s system chooser. Pocket Luach does not receive the shared content.

Deleting local data

Users can remove Birthday Tehilim profiles and Personal Tehilim entries individually, clear all saved birthday profiles in the feature, delete custom locations individually, or remove all app data through Android Settings or by uninstalling. Removing a profile removes only its dynamic Personal Tehilim reference; static personal Psalms remain. Pocket Luach operates no server and has no server-side account data.

Changes

This policy will be updated before any material change to the app’s data handling.
