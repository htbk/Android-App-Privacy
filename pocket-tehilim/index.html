Pocket Tehilim Privacy Policy

Effective August 16, 2026

Pocket Tehilim is published by Tebeka Software Solutions. Privacy questions may be sent to haim@tebeka.com.

Privacy by design

Pocket Tehilim works offline and does not require an account. It contains no advertising, analytics, tracking, crash-reporting, billing, or remote-content service. It does not collect, transmit, sell, or share personal data.

On-device content and preferences

Hebrew and English Psalm text is bundled with the app. Reading language, appearance, text size, personal chapter selections, and reading position are kept in Android app-private storage. The reader disables JavaScript and network loading.

Optional Birthday Tehilim information

If the user enables Birthday Tehilim, the app can store any number of optional named birthday profiles. Each profile contains only an editable display name, full civil birth date, the user’s before-sunset, after-sunset, or not-sure choice, a local app identifier and ordering, and whether its dynamic Psalm is included in My Tehilim. Those values are used only on the device to derive the Hebrew birthday, current year of life, and daily Psalm. The Psalm is recalculated automatically as the person’s Hebrew age changes. These values are never sent to Tebeka Software Solutions or another party.

The optional Android system contact picker temporarily makes only the contact selected by the user available to Pocket Tehilim. The app copies an editable display name and a full birthday when those fields are available, then discards the selected contact reference. It never stores a contact URI or identifier, phone number, email address, postal address, or any other contact field. A missing birthday, missing year, unavailable field, or provider error requires manual entry; cancelling the picker makes no changes. The app does not create an ongoing Contacts link.

Pocket Tehilim requests no user-granted Android permissions—including no broad Contacts permission—or Internet access, does not create a calendar event, reminder, or notification, and does not determine the local sunset instant. Its annual recommendation follows the Hebrew date displayed from the device’s civil date and may therefore change at midnight rather than sunset.

Android backup and device transfer

Birthday profile names, dates, sunset choices, local identifiers, ordering, and dynamic My Tehilim references use a dedicated DataStore file in Android’s no-backup directory, which Android excludes from cloud backup and device transfer. The restrictive backup rules also do not include the regular file-based DataStore area used for reading preferences. Pocket Tehilim operates no server and has no server-side user data.

Deleting local data

Each birthday profile can be edited or removed, and all birthday profiles can be cleared directly from Birthday Tehilim. Removing a profile also removes its dynamic My Tehilim reference; static personal Psalms remain. Other local app data remains until the user changes it, clears the app’s storage, or uninstalls the app. Because no account or server data exists, there is no separate account-deletion process.

Changes

This policy will be updated before a release adds networking, analytics, advertising, accounts, cloud sync, or another material data-handling feature.
